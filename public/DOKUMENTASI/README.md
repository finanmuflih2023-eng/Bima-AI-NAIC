# Website Dokumentasi Proyek BIMA — NAIC 2026

Direktori ini berisi seluruh source code website dokumentasi resmi untuk proyek **BIMA (Bisa Basa Krama): Autonomous Multi-Agent System for Javanese Krama Learning, Adaptive Pronunciation Evaluation, and Pedagogical Intelligence** yang siap Anda upload/hosting online.

---

## 📂 Struktur Berkas di Folder Ini:

- **`index.html`** : Halaman utama dokumentasi web interaktif, lengkap dengan navigasi, perincian 3 AI Agent, spesifikasi teknis, quickstart guide, dan simulator tes ucapan Krama.
- **`style.css`** : Stylesheet modern bertema putih-biru cerah yang responsif di PC, tablet, maupun HP.
- **`script.js`** : Interaktivitas untuk tombol *Salin Kode (Copy to Clipboard)* dan *Live Simulator Deteksi Pelafalan Lisan*.
- **`images/`** : Seluruh aset visual beresolusi tinggi, termasuk diagram arsitektur multi-agent, infografis urgensi masalah, dan tangkapan layar antarmuka sistem.

---

## 🚀 Cara Mudah Upload & Hosting Jadi Website Online:

### Pilihan 1: Hosting Gratis via Vercel (Paling Cepat & Mudah - 1 Menit)
1. Buka [vercel.com](https://vercel.com) dan login (bisa via akun GitHub).
2. Klik tombol **"Add New Project"** lalu drag-and-drop folder `DOKUMENTASI` ini.
3. Klik **"Deploy"**. Web langsung aktif dan memiliki link publik (misal: `bima-docs.vercel.app`).

### Pilihan 2: Hosting Gratis via GitHub Pages
1. Buat repository baru di GitHub (misal: `bima-documentation`).
2. Upload seluruh isi folder `DOKUMENTASI` ini ke root repository tersebut.
3. Buka menu **Settings** > **Pages** > pada bagian Branch pilih **main** dan folder **/ (root)**, lalu klik **Save**.
4. Website akan aktif dalam 1-2 menit di URL: `https://<username>.github.io/bima-documentation/`.

### Pilihan 3: Hosting via Netlify Drop
1. Buka [app.netlify.com/drop](https://app.netlify.com/drop).
2. Tarik (*drag and drop*) folder `DOKUMENTASI` ini langsung ke jendela browser.
3. Website akan langsung aktif seketika.
